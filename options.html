01 · DESTINO E ENVIO

Do eproc para o Notebook

Abra a capa do processo e clique em Enviar processo ao Notebook. A extensão seleciona os documentos, captura o PDF integral e envia para o destino abaixo.

Use o link de um notebook específico. Se houver mais de uma conta Google, mantenha o parâmetro authuser no link.

O PDF é enviado diretamente. Nenhuma pasta, janela Salvar como ou programa adicional é necessário.

Última etapa do envio

Nenhum andamento registrado.

02 · BIBLIOTECA

Seus prompts do Drive

Mantenha um arquivo .txt ou .md por prompt na pasta pública. Edite no Drive e atualize a biblioteca quando quiser.

Acesso à biblioteca do DriveA atualização da pasta pública usa a API do Drive. Ative essa API e restrinja a chave a ela.
03 · PROMPTS LOCAIS

Adicionar um prompt

Os prompts locais aparecem no menu do Notebook junto com os da sua biblioteca.

    Outras opções

    Na capa do processo, o botão fica ao lado de Imprimir. Nas outras páginas, arraste o botão Easy Notebook para reposicioná-lo. A posição fica salva neste navegador, tanto no eproc quanto no Notebook.

    Para enviar um PDF que já está no computador, selecione o arquivo completo.
