## Instalação em Downloads

O guia agora orienta a manter o destino padrão do Windows e clicar em Extrair. Na seleção do Chrome, o caminho é Downloads → Easy-Notebook-0.21.4 → Easy Notebook.

Não é mais necessário criar Eprocando nem mudar a extração para Documentos. O guia lembra de manter a pasta extraída e explica como reconhecer downloads com sufixo (1).

Compartilhe o [guia de instalação](https://rambond123.github.io/easy-notebook/). Para download direto, use Easy-Notebook-0.21.4.zip; Source code é o projeto de desenvolvimento.
