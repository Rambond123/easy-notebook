Easy NotebookInstalação no Chrome

Aqui neste guia

Primeiro, baixe a extensão

Vamos instalar juntos. Você verá uma etapa de cada vez e avançará quando terminar.

Baixar Easy Notebook

O Chrome baixará um arquivo chamado Easy-Notebook-0.22.5.zip. Aguarde o download terminar.

Já baixou esse arquivo? Pode seguir em Já baixei →.

Deixe este guia aberto para consultar as próximas etapas.

Na pasta Downloads do Windows

Clique com o botão direito no ZIP

  1. No Chrome, pressione Ctrl + J para ver os downloads.
  2. Ao lado de Easy-Notebook-0.22.5.zip, clique no ícone de pasta (Mostrar na pasta).
  3. Na janela que abriu, clique com o botão direito sobre o ZIP e escolha Extrair Tudo….
Referência visual • faça isso na janela do Windows
📦 Easy-Notebook-0.22.5.zipExtrair Tudo…↑ Escolha esta opção no menu do botão direito

Não precisa abrir nem escolher nenhum dos arquivos de código.

Na janela “Extrair Pastas Compactadas” do Windows

Deixe em Downloads e clique em “Extrair”

Mantenha o local que o Windows já preencheu. Clique em Extrair e aguarde terminar.

Destino padrão • o Windows cria uma pasta com o nome do ZIP
📁 Downloads📁 Easy-Notebook-0.22.5📁 Easy NotebookExtrair

Guarde a pasta nesse lugar. O Chrome usará os arquivos dela sempre que a extensão funcionar.

Em uma nova guia do Chrome

Abra a tela de extensões

Clique no botão abaixo para copiar o endereço:

  1. Pressione Ctrl + T para abrir uma nova guia.
  2. Cole com Ctrl + V na barra de endereço e pressione Enter.
  3. Volte a este guia para ver o próximo passo.

Na guia “Extensões” do Chrome

Ative “Modo do desenvolvedor”

No canto superior direito da tela de extensões, clique na chave ao lado de Modo do desenvolvedor. Ela deve ficar ativada.

Referência visual • procure esta chave na outra guia do Chrome
ExtensõesModo do desenvolvedor
A opção está bloqueada ou não aparece?

Amplie a janela e confira o canto superior direito. Se o Chrome informar que a opção foi desativada pela organização, este método não consegue concluir a instalação nesse perfil.

Ainda na guia “Extensões” do Chrome

Clique em “Carregar sem compactação”

O botão aparece no canto superior esquerdo, depois de ativar o modo do desenvolvedor. Clique nele para escolher a pasta.

Referência visual • clique no botão da tela de extensões
Carregar sem compactaçãoCompactar extensãoAtualizar

Se estiver escrito Carregar expandida, é a mesma opção.

Na janela de seleção de pasta que acabou de abrir

Selecione a pasta Easy Notebook

  1. Na lateral da janela, clique em Downloads.
  2. Abra a pasta Easy-Notebook-0.22.5 que foi criada ao extrair e depois a pasta Easy Notebook dentro dela.
  3. Clique em Selecionar pasta, na parte de baixo da janela.
Referência visual • confira o nome da pasta antes de confirmar
📁 Downloads  ›  Easy-Notebook-0.22.5  ›  Easy NotebookOs arquivos podem não aparecer neste seletor. Isso é normal.Selecionar pasta
Minha pasta tem outro nome ou não está em Downloads

Se baixou o ZIP mais de uma vez, a pasta pode terminar em (1) ou outro número. Abra a pasta criada na sua extração e, dentro dela, Easy Notebook. Se escolheu outro local para baixar, procure nesse local.

O Chrome diz que não encontrou o manifesto?

Abra a pasta Easy Notebook que fica dentro da pasta extraída Easy-Notebook-0.22.5. É essa pasta interna que deve ser selecionada.

No Chrome

Confira se apareceu “Easy Notebook”

A instalação deu certo se o cartão Easy Notebook apareceu na tela de extensões com a chave ativada.

  1. O assistente da extensão deve abrir para configurar seu notebook. Siga as instruções dele.
  2. Se não abrir, clique no ícone de quebra-cabeça ao lado da barra de endereços e escolha Easy Notebook.
  3. Depois de configurar, atualize a página do eproc com F5.

Mantenha a pasta extraída Easy-Notebook-0.22.5 em Downloads, com a pasta Easy Notebook dentro dela. O Chrome precisa desses arquivos. Você pode apagar apenas o arquivo .zip.

Pronto. Você pode fechar este guia.
