## Instalação guiada para colegas

**Comece pelo [guia de instalação](https://Rambond123.github.io/easy-notebook/).** Esse é o link para compartilhar.

O guia abre antes do download, mostra uma etapa por vez e indica em qual janela agir. Inclui referências visuais com destaque dos controles, botão para copiar o endereço das extensões e orientação para guardar a extensão em Documentos → Eprocando → Easy Notebook.

O arquivo **Easy-Notebook-0.21.3.zip** abaixo é o pacote de instalação. Ele contém somente o guia e a pasta Easy Notebook, onde ficam os arquivos usados pelo Chrome. Não é preciso abrir os arquivos de código.

Não baixe **Source code** para instalar: esse é o projeto de desenvolvimento.

Validação: oito etapas percorridas em Chromium, navegação de ida e volta, cópia e alternativa quando a cópia é bloqueada, exibição a 390 pixels, inspeção visual e conferência do conteúdo do ZIP. O procedimento completo em computador gerenciado do tribunal não foi validado nesta versão.
